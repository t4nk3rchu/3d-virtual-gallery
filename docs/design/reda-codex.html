REDA · The Curator's Codex

The workbench reimagined as an open manuscript. The surface is vellum; the index is a hand-kept ledger; the 3D room is an engraving plate set into the page with its plan drawn beside it; the artwork record is a catalogue entry with an illuminated initial and marginalia. Rubrics (headings) in red ink, illumination in gold — the Renaissance codex as a working tool.
